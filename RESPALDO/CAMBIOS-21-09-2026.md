# RESUMEN DE CAMBIOS - 21/09/2026

## Correcciones realizadas

### 1. Tarjetas duplicadas de becas (CORREGIDO)
**Problema:** Al publicar una entrada con etiqueta "Beca", aparecían 2 tarjetas:
- Tarjeta 1 (incorrecta): Solo mostraba "BECA", título y "VER BECA" — del sistema JSONP original del tema
- Tarjeta 2 (correcta): Mostraba categoría "movilidad", etiqueta "Nuevo", título, institución, etc. — del sistema dinámico

**Causa:** Ambos sistemas cargaban becas desde `/feeds/posts/default/-/Beca` y las insertaban en el mismo `#becasGrid`.

**Solución:** Se desactivó `cargarPortal(SECCIONES.becas)` en la línea 5984 del tema, que era el sistema JSONP original. Ahora solo funciona el sistema dinámico (`cargarBecasDinamicas()`).

### 2. Texto de becas más extenso (MEJORADO)
**Problema:** Las instrucciones para ChatGPT pedían textos muy breves (4-6 líneas por descripción).

**Solución:** Se actualizaron las instrucciones en `INSTRUCCIONES-BECAS-CHATGPT.md`:
- Descripción: mínimo 8-12 líneas
- Beneficios: 5-7 items con explicación detallada
- Requisitos: 5-8 items con contexto
- Cómo postular: 5-7 pasos detallados
- Nueva sección: "Consejos para postulantes" (3-5 tips)
- Nueva sección: "Preguntas frecuentes" (3-5 preguntas)
- Objetivo: mínimo 500 palabras

### 3. Campos ocultos en template de becas (NUEVO)
**Problema:** El JS buscaba campos como `Tipo: universitaria` en el HTML del post, pero el template visual no los incluía.

**Solución:** Se agregó un bloque oculto al inicio del template:
```html
<div style="display:none;">
<div>Tipo: [tipo]</div>
<div>Rama: [rama]</div>
<div>Nivel: [nivel]</div>
<div>Cobertura: [cobertura]</div>
<div>Institución: [INSTITUCIÓN]</div>
<div>Fecha de cierre: [DD/MM/AAAA]</div>
</div>
```
