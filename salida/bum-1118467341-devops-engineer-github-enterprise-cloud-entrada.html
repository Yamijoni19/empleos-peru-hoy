Descripción del puesto

En Indra seguimos creciendo y buscamos profesionales con sólida experiencia en DevOps, GitHub Enterprise Cloud y automatización de pipelines , que quiera asumir un rol clave en la estandarización, evolución y adopción de buenas prácticas DevOps. &#x1f50e; ¿Qué harás en el rol? Diseñar, implementar y optimizar pipelines de integración y despliegue continuo (CI/CD) . Gestionar y administrar repositorios en GitHub Enterprise Cloud . Diseñar workflows reutilizables y composite y estandarizar procesos de automatización. Implementar y promover buenas prácticas de desarrollo, versionamiento y DevOps . Gestionar el flujo de trabajo ágil mediante herramientas de planificación y seguimiento

. Implementar prácticas de Docs as Code , asegurando documentación versionada, automatizada y mantenible. Participar o liderar procesos de migración tecnológica hacia plataformas GitHub . Brindar capacitaciones técnicas y acompañamiento a los equipos en prácticas DevOps. &#x1f4a1; ¿Qué buscamos? ✅ 5 años de experiencia profesional. ✅ Experiencia experta en GitHub Enterprise Cloud , incluyendo repositorios, GitHub Actions y GitHub Advanced Security (GHAS) . ✅ Experiencia en diseño e implementación de workflows reutilizables y composite , así como en estandarización de pipelines CI/CD. ✅ Experiencia intermedia/avanzada en Azure Boards , incluyendo personalización de procesos, WIQL y generación de dashboards y métricas como Lead Time / Cycle Time . ✅ Experiencia implementando prácticas de Docs as Code . ✅ Experiencia en procesos de migración hacia plataformas DevOps , especialmente GitHub. ✅ Experiencia brindando capacitaciones técnicas y acompañamiento a equipos . ✅ Experiencia trabajando en entornos ágiles y colaborativos .
