Descripción del puesto

Gelar Master/PhD di bidang Statistik, Matematika Terapan, Ilmu Komputer, Data Science, atau bidang terkait. Además, Memiliki pengalaman minimal 2 tahun dalam data science, analitik, dan pemodelan data, serta minimal 1 tahun pengalaman proyek Machine Learning/Deep Learning end-to-end. Asimismo, Memiliki pemahaman kuat mengenai statistik, machine learning, deep learning (CNN, LSTM, Transformer, Embedding), feature engineering, dan evaluasi model.

Berpengalaman dalam EDA, pengembangan dan optimasi model, eksperimen data (A/B testing), serta model explainability. Además, Familiar dengan Python, Dataiku Visual ML, dan Dataiku Custom Modeling menjadi nilai tambah. Asimismo, Menerjemahkan kebutuhan bisnis menjadi solusi berbasis Machine Learning dan Deep Learning.
