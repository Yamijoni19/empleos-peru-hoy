Descripción del puesto

Liderar técnicamente la práctica backend durante todo el ciclo de vida del desarrollo (SDLC). Además, Establecer, conservar y evolucionar los lineamientos, estándares y buenas prácticas de desarrollo backend, promoviendo la estandarización de componentes, frameworks y patrones de implementación. Asimismo, Diseñar e implementar soluciones serverless seguras de extremo a extremo sobre AWS (CloudFront, WAF, API Gateway, Lambda Authorizers, Lambda, DynamoDB), asegurando escalabilidad, seguridad y alta disponibilidad, con manejo correcto de tokens, headers y sesiones.

Guiar técnicamente y ofrecer mentoría al equipo en el uso de servicios AWS, patrones de arquitectura y buenas prácticas de ingeniería; efectuar revisiones de código y asegurar la ejecución de pruebas unitarias. Además, Impulsar la adopción de prácticas DevSecOps, automatización, CI/CD e Infraestructura como Código: Terraform con despliegues por ambientes vía Bitbucket Pipelines, manteniendo los quality gates (Sonar, Trivy, Gitleaks, Semgrep, linters y tests) como barrera obligatoria de calidad y seguridad. Asimismo, Garantizar el cumplimiento de los lineamientos de desarrollo seguro: secretos en Parameter Store/Secrets Manager con KMS, authorizers, patrones de validación de origen, hashing de credenciales/tokens, y remedíación de hallazgos de ethical hacking.

Funciones

  • Liderar técnicamente la práctica backend durante todo el ciclo de vida del desarrollo (SDLC).
  • Definir, mantener y evolucionar los lineamientos, estándares y buenas prácticas de desarrollo backend, promoviendo la estandarización de componentes, frameworks y patrones de implementación.
  • Diseñar e implementar soluciones serverless seguras de extremo a extremo sobre AWS (CloudFront, WAF, API Gateway, Lambda Authorizers, Lambda, DynamoDB), asegurando escalabilidad, seguridad y alta disponibilidad, con manejo correcto de tokens, headers y sesiones.
  • Guiar técnicamente y brindar mentoría al equipo en el uso de servicios AWS, patrones de arquitectura y buenas prácticas de ingeniería; realizar revisiones de código y asegurar la ejecución de pruebas unitarias.
  • Impulsar la adopción de prácticas DevSecOps, automatización, CI/CD e Infraestructura como Código: Terraform con despliegues por ambientes vía Bitbucket Pipelines, manteniendo los quality gates (Sonar, Trivy, Gitleaks, Semgrep, linters y tests) como barrera obligatoria de calidad y seguridad.
  • Garantizar el cumplimiento de los lineamientos de desarrollo seguro: secretos en Parameter Store/Secrets Manager con KMS, authorizers, patrones de validación de origen, hashing de credenciales/tokens, y remedíación de hallazgos de ethical hacking.
  • Modelar y operar DynamoDB (claves, TTL, sesiones cifradas) y las integraciones con bases de datos on-premise, resolviendo incompatibilidades entre runtimes, drivers y versiones de BD; liderar las migraciones de runtimes y dependencias evaluando riesgos antes del despliegue.
  • Implementar la observabilidad del backend: logs estructurados, correlation IDs, métricas, alarmas y díagnóstico en DEV/QA/PRD.
  • Validar la documentación técnica y de despliegue antes de la liberación a los diferentes ambientes.
  • Documentar decisiones técnicas, levantar riesgos oportunamente, identificar oportunidades de mejora continua en procesos, arquitectura y herramientas, y ejercer criterio propio sobre qué puede y qué no puede ir a producción.

Requisitos

  • Mínimo 5 años liderando equipos técnicos de desarrollo backend, incluyendo revisiones de código (code review) y mentoría técnica.
  • Experiencia implementando soluciones Cloud Native y serverless seguras en producción sobre AWS: Lambda, API Gateway, Lambda Authorizers, DynamoDB, Parameter Store, Secrets Manager, IAM (roles/policies), CloudWatch, CloudFront, WAF y KMS, con manejo de ambientes DEV / QA / PRD. Deseable: Amazon ECS/Fargate, EKS y RDS.
  • Experiencia diseñando arquitecturas escalables, resilientes y seguras, y APIs REST con contratos OpenAPI/Swagger, validación de entrada/salida, manejo estandarizado de errores HTTP, trazabilidad por request y separación por capas o arquitectura hexagonal.
  • Experiencia implementando prácticas DevOps y DevSecOps: Terraform (módulos, variables por ambiente), Bitbucket Pipelines y quality gates con SonarQube, Trivy, Gitleaks, Semgrep, linters y tests unitarios obligatorios. Deseable: Checkov, GitHub Actions, Jenkins o GitLab CI.
  • Experiencia liderando migraciones de runtimes y dependencias (versiones de Node.js, librerías nativas, AWS SDK) y resolviendo incompatibilidades entre runtime, driver y versión de base de datos, incluyendo conectividad desde Lambda hacia bases de datos on-premise (p. ej. Oracle).
  • Node.js/TypeScript sólido para desarrollo backend: Node 18/20/22+ y sus ciclos de soporte, AWS SDK v3, handlers async/await, Jest o Vitest, ESLint y gestión de dependencias vulnerables. Deseable: Java 17+ con Spring Boot (Maven/Gradle, JUnit/Mockito), Python 3.11+ (Lambdas, boto3, Pytest, FastAPI) o .NET.
  • Arquitecturas Serverless y Event-Driven Architecture; patrones de diseño y principios SOLID.
  • Seguridad de APIs: OWASP Top 10, JWT, OAuth2/OpenID Connect a nivel práctico, tokens nominados vs anónimos, headers de seguridad, CORS, rate limiting, gestión de secretos (sin hardcodear, sin exponer credenciales en frontend), cifrado/KMS, hashing con salt & pepper y patrones de validación de origen entre CloudFront, API Gateway y Lambda.
