Descripción del puesto

Bertanggung jawab untuk mengembangkan, mengimplementasikan, mengoptimalkan dan memelihara end to end solusi Machine Learning untuk mendukung kebutuhan bisnis, serta memastikan kualitas dan keberhasilan inplementasi solusi yang menjadi tanggung jawabnya. Además, S1 jurusan Computer Science, Data Science, Statistika, Matematika atau jurusan terkait. Además, Memiliki pengalaman mengembangkan Solusi AI/ML secara end to end, mulai dari data preparation, fitur engineering, model development, deployment, monitoring hingga continuous improvement. Asimismo, Memiliki pemahaman mendalam mengenai Bahasa pemograman Phyton dan software engineering fundamental (OOP, Algorithms, Data Structures, testing, code visioning dll).
