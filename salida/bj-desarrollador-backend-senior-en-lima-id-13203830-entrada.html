Funciones

  • Desarrollar y mantener servicios backend, APIs y microservicios con Python sobre AWS.
  • Diseñar y administrar modelos de datos en bases de datos SQL y NoSQL.
  • Ejecutar pruebas y asegurar la calidad, seguridad y rendimiento de las aplicaciones.
  • Implementar procesos CI/CD y despliegues automatizados.
  • Monitorear servicios productivos, resolver incidentes y optimizar el desempeño de las soluciones.
  • Colaborar con equipos de desarrollo, arquitectura y producto para la implementación de soluciones tecnológicas escalables.
  • Elaborar documentación técnica y aplicar buenas prácticas de desarrollo de software.

Requisitos

  • Titulado(a) en Ingeniería de Sistemas, Ingeniería Informática, Ciencias de la Computación, Ingeniería de Software o carreras afines.
  • Experiencia mínima de 5 años en desarrollo Backend.
  • Experiencia sólida desarrollando aplicaciones con Python.
  • Experiencia comprobada trabajando con AWS Serverless (Lambda, API Gateway y servicios relacionados).
  • Experiencia en diseño, desarrollo e integración de APIs RESTful.
  • Conocimiento y experiencia en implementación de pipelines CI/CD y automatización de despliegues.
  • Experiencia administrando y soportando aplicaciones en ambientes productivos de alta disponibilidad.
  • Conocimiento de bases de datos relacionales (SQL) y no relacionales (NoSQL).
